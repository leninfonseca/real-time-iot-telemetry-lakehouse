# Real-Time IoT Telemetry Lakehouse

End-to-end Data Engineering project for real-time IoT telemetry ingestion and lakehouse analytics.

## Project goals

This repository is currently an initial project skeleton. The architecture, pipelines, notebooks, SQL models, tests and documentation will be implemented progressively as the project is built.

## Repository structure

- `architecture/` — architecture diagrams and design documentation
- `notebooks/` — data engineering notebooks
- `sql/` — SQL modeling and analytical queries
- `pipelines/` — pipeline documentation and configuration notes
- `docs/` — data model, data quality and engineering decisions
- `tests/` — validation and data-quality tests
